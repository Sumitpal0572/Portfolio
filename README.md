# 💼 My Portfolio

Welcome to my **Developer Portfolio** — a dynamic and modern web-based resume showcasing my projects, experience, education, and skills. Built using **React**, **Tailwind CSS**, and enhanced with interactive **tilt effects**, **texture backgrounds**, and a **functional contact form** via email

## 🚀 Features

- **About Me**: Brief overview of who I am, what I do, and my career goals.
- **Projects**: Highlighted list of my key projects with visuals and links.
- **Skills**: Visualized list of my technical skills and tools I’m proficient in.
- **Experience**: Timeline or card-based layout of my job/internship history.
- **Education**: Academic qualifications and related certifications.
- **Contact**: A working email form to reach me directly.
- **Download CV**: Button to download my resume.
- **Social Media Links**: Icons for GitHub, LinkedIn, and other platforms.

## 🧰 Technologies Used

- **React.js** – Frontend library for building UI components
- **Vite** – Fast development server and build tool
- **Tailwind CSS** – Utility-first CSS framework for responsive design
- **JavaScript (ES6+)** – Logic and interactivity
- **HTML5 & CSS3** – Structure and styling
- **EmailJS** – For handling email functionality in contact form
- **React-Tilt / Parallax Tilt** – For the tilt card effects
- **MUI (Material UI)** – For polished and responsive UI components (if used)
- **React Icons** – For social media and interface icons
- **Git & GitHub** – Version control and collaboration.

## 📁 Installation & Setup

Follow these steps to run this project locally:

```bash
# 1. Clone the repository
git clone https://github.com/Sumitpal0572/Portfolio

# 2. Navigate into the project directory
cd portfolio-react

# 3. Install all dependencies
npm install

# 4. Start the development server
npm run dev
```
